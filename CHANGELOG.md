# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.0.2] - 2026-09-03

### Changed

* Removed HTML-based layout elements from the README.

## [1.0.1] - 2026-09-03

### Changed

* Updated the project README for improved NuGet.org compatibility.
* Removed HTML-based layout elements from the README.
* Removed the embedded README logo to prevent rendering issues on NuGet.org.
* Improved documentation, NuGet, examples and project resource links.
* Improved README presentation across GitHub and NuGet.org.

## [1.0.0] - 2026-09-03

### Added

* Initial public release of Validtron.
* Strongly-typed fluent validation API.
* Synchronous and asynchronous validation support.
* Conditional validation rules.
* Configurable cascade modes.
* Nested object validation.
* Collection validation.
* Custom validation rules and error messages.
* Structured validation results with property-based error access.
* Dependency injection support for modern .NET applications.
* Sample project and usage examples.
* GitHub Pages documentation and Quick Start guide.
* NuGet package distribution.
* Comprehensive project README with installation, quick start, feature overview, usage examples, documentation links and contribution guidance.
