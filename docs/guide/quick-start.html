Quick Start

Define expressive validation rules, run them synchronously or asynchronously, and integrate validators with your .NET dependency injection container.

01 Installation

Add Validtron to your project using the .NET CLI.

Terminal
$ dotnet add package Validtron
Target frameworkThe current library project targets net10.0.

02 Create your first validator

Inherit from Validator<T>, then declare rules using RuleFor.

UserValidator.cs
using Validtron;
using Validtron.Extensions;

public sealed class UserValidator : Validator<User>
{
    public UserValidator()
    {
        RuleFor(x => x.Email)
            .NotEmpty()
            .EmailAddress();

        RuleFor(x => x.Age)
            .GreaterThanOrEqual(18)
            .LessThan(100);
    }
}

Validtron also exposes rules for lengths, ranges, enums, regular expressions and custom predicates, plus custom error messages.

03 Run validation

Call Validate for purely synchronous rules. The result exposes IsValid, a detailed Errors list and grouped ErrorsByProperty.

Validation
var result = new UserValidator().Validate(user);

if (!result.IsValid)
{
    foreach (var error in result.Errors)
    {
        Console.WriteLine(
            $"{error.PropertyName}: {error.ErrorMessage}");
    }
}

04 Async validation

For rules that depend on I/O, define an asynchronous predicate with MustAsync and execute the validator with ValidateAsync.

Async rule
RuleFor(x => x.UserName)
    .NotEmpty()
    .MustAsync(async (value, ct) =>
        !await userStore.ExistsAsync(value!, ct));

var result = await validator.ValidateAsync(model, ct);
Sync vs asyncA validator containing async rules should be executed with ValidateAsync.

05 Conditional rules & cascade

Attach rules only when they make sense for the current object, and choose whether the chain continues after a failure.

Conditional validation
RuleFor(x => x.TaxNumber)
    .NotEmpty()
    .Length(10, 10)
    .When(x => x.IsCompany);

RuleFor(x => x.Name)
    .Cascade(CascadeMode.Continue)
    .NotEmpty()
    .MinimumLength(3);

06 Nested objects & collections

Reuse validators across object graphs with SetValidator, and apply rules to collection elements with RuleForEach.

Composition
RuleFor(x => x.Address)
    .SetValidator(new AddressValidator());

RuleForEach(x => x.PreviousAddresses)
    .SetValidator(new AddressValidator());

RuleForEach(x => x.Tags)
    .NotEmpty()
    .MinimumLength(2);

07 Dependency injection

Validtron can scan an assembly and register concrete validators as scoped implementations of IValidator<T>.

Program.cs
using Validtron.DependencyInjection;

services.AddValidtron(
    typeof(Program).Assembly);

// Then inject the validator where you need it.
public sealed class UserService(
    IValidator<User> validator)
{
}
